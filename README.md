# نبض NABDH — نموذج أولي لتطبيق هاتف

## ما الذي يتضمنه؟
- واجهة عربية RTL بتصميم داكن.
- صفحة رئيسية واستكشاف.
- غيمة الذكاء: أسئلة منطقية قصيرة ونتيجة تدريبية.
- مرآة الشخصية: أسئلة تأمل ذاتي، دون تشخيص نفسي أو تصنيف سايكوباث.
- مختبر سلوك المساعد: سيناريوهات تعليمية.
- تفضيلات محلية وعدادات نشاط للجلسة.

## تشغيل المشروع
يتطلب جهاز كمبيوتر عليه Node.js وnpm، واتصالاً بالإنترنت لتثبيت الحزم.

1. فك ضغط الملف.
2. افتح الطرفية داخل مجلد `Nabdh`.
3. نفّذ:
   ```bash
   npm install
   npx expo start
   ```
4. ثبّت تطبيق **Expo Go** على هاتف Android ثم امسح رمز QR الذي يظهر في الطرفية/المتصفح.

## بناء نسخة Android قابلة للتثبيت (APK)
هذه ملفات المصدر وليست APK جاهزاً. لبناء APK باستخدام EAS Build:
1. أنشئ حساباً على Expo.
2. داخل المجلد نفّذ `npx eas-cli@latest login`.
3. نفّذ `npx eas-cli@latest build:configure`.
4. أنشئ ملف `eas.json` بالمحتوى التالي:
   ```json
   {
     "build": {
       "preview": {
         "distribution": "internal",
         "android": { "buildType": "apk" }
       },
       "production": {
         "android": { "buildType": "app-bundle" }
       }
     }
   }
   ```
5. لبناء APK للتجربة: `npx eas-cli@latest build --platform android --profile preview`
6. للنشر على Google Play عادةً تحتاج ملف AAB: `npx eas-cli@latest build --platform android --profile production` ثم ارفع الناتج إلى Google Play Console.

## قبل النشر
- غيّر `com.nabdh.app` إلى معرّف حزمة تملكه وفريداً.
- اختبر التطبيق على أجهزة فعلية وأصلح أي ملاحظات.
- جهّز سياسة خصوصية دقيقة وإفصاحات متجر Google Play ونموذج Data safety وفق البيانات الفعلية.
- جهّز أيقونة ولقطات شاشة ووصفاً وتصنيف محتوى مناسباً.
- لا تصف اختبار غيمة الذكاء بأنه اختبار IQ معياري؛ ولا تعرض مرآة الشخصية كأداة تشخيص نفسي.
- النسخة الحالية نموذج محلي: لا تسجيل دخول، لا قاعدة بيانات سحابية، ولا نموذج AI خارجي متصل.
